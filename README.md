# 我的世界 · 网页版

待办 · DDL 倒计时 · 课程表 · 便签 的个人管理面板。纯网页，手机和电脑都能打开，
配置同一个 GitHub Token 后数据自动同步，并可「添加到主屏幕」像 App 一样一键打开。

**线上地址**：<https://Origin2019.github.io/my-world/>

---

## 云同步原理（为什么用 GitHub Gist）

- 数据保存在你自己的一个**私密 Gist**（GitHub 的代码片段仓库，只有你能看到）里。
- 手机和电脑只需填入**同一个 GitHub Token**，就会自动找到同一个 Gist 并同步。
- `api.github.com` 国内手机、电脑都能直连，**不需要代理、不需要额外服务器**。
- 本地 `localStorage` 始终是工作副本，断网也能正常用，联网后自动补同步。

---

## 第一步：生成一个 GitHub Token（只做一次）

1. 电脑浏览器打开（已自动勾好 `gist` 权限）：

   👉 <https://github.com/settings/tokens/new?description=my-world&scopes=gist>

2. 拉到底部点 **Generate token**。
3. 复制页面上出现的那串 **`ghp_...`**（**只会显示这一次**，先粘到记事本存好）。
4. 这个 Token 只会被本机浏览器保存在 `localStorage`，不会上传到任何第三方。

> 权限只有 `gist` 一项，即使泄露也无法操作你的代码仓库。

---

## 第二步：在网页里连接

1. 打开 <https://Origin2019.github.io/my-world/>
2. 点右上角 **☁ 未连接** → 把 `ghp_...` 粘进去 → 点 **连接**。
3. 第一次会自动创建云端数据并上传；以后进来会自动同步。

### 手机上怎么配（最省事）

在**已连接的电脑**上点面板里的 **📱 生成手机配置链接**，复制弹出的那条链接，
发到手机（微信发给自己 / QQ 等），手机点开一次就会自动配置好，无需手打长串 Token。

也可以手动在手机上进面板粘贴同一个 Token。

---

## 手机怎么用

1. 手机浏览器打开 <https://Origin2019.github.io/my-world/>（**别用微信内置浏览器**）。
2. **iPhone（Safari）**：点底部「分享」→ **添加到主屏幕**。
   **安卓（Chrome）**：点右上角「⋮」→ **添加到主屏幕 / 安装应用**。
3. 桌面上就多了一个「我的世界」图标，以后点它直接打开，跟原生 App 一样。
4. 按上面第二步连接好 Token，数据立刻和电脑互通。

> 电脑上想装成 App：用 Edge/Chrome 打开网址，地址栏右侧会出现「安装」图标，点一下即可。

## 把电脑上桌面版的老数据搬过来

原来 Electron 版的数据都在 `userdata.json` 里（本地备份在 `D:\Backup\my-world-20261016\`）。

1. 电脑浏览器打开网页版。
2. 点 **☁** → **从文件导入数据**，选中 `userdata.json`。
3. 页面刷新后会自动同步到云端 → 手机连接同一 Token 即可看到。

（反过来也可用 **导出备份** 把网页版数据存成 json 文件留底。）

## 常见问题

- **显示「❌ 上传失败 / 读取失败」？** 点面板里的 **🔍 测试连接** 看具体报错。
  多数是 Token 过期（GitHub 默认 90 天）或网络问题。
- **手机和电脑不同步？** 确认两端填的是**同一个 Token**。改完后 1.5 秒自动上传；
  另一台设备**切回页面时会立刻拉取一次**，否则最多等 60 秒。也可以打开面板点「立即同步」。
- **怕旧数据把新数据覆盖？** 不会了。同步前会先比对**内容**：云端没被别的设备改过才上传；
  云端确实更新了（而且比本机改动新）就下载。每次覆盖前都会自动留一份备份（面板里可「↩ 恢复本机备份」）。
- **Token 过期了怎么办？** 重新生成一个，在面板里断开连接后重新连（云端数据不会丢）。
- **在两台设备同时改同一条**，以最后修改的那台为准（个人工具够用，不做逐条合并）。
- **不连接能不能用？** 能。未连接时数据只存在当前浏览器本地，只是不能跨设备同步。
- **更新后按钮点了没反应 / 界面是旧版？** 浏览器可能缓存了旧页面。电脑按 `Ctrl+F5` 强制刷新，
  手机下拉刷新一次即可（新版 Service Worker 已改成每次向服务器校验，以后不会再有这个问题）。
- **悬浮待办点了没反应？** 已修复：即使浏览器缓存着旧页面，程序也会自动补出悬浮面板。
- **注意隐私**：GitHub Pages 上的网页是公开的，任何人都能打开你的网址，但打开后是空的
  （他们没有你的 Token）。你的数据只存在你自己的私密 Gist 里。

## 功能说明

### 悬浮待办（带进度条）
在带进度条的待办上点 **📌**，它就会被固定到页面最上层的悬浮窗里：
- 拖动标题栏可以调整位置（位置会记住）
- 悬浮窗里的勾选框和主界面是同一份数据，勾哪边都同步
- 标题栏 **－** 收起 / 展开，**×** 关闭（取消全部固定）
- 只有带进度条的待办能固定（右键待办 → 添加进度条）

### 置顶小窗：待办浮在「任何程序」之上（🪟）
页面里的悬浮窗只能浮在本网页上面。要让待办**浮在记事本、浏览器等任意窗口之上**，
点悬浮窗标题栏的 **🪟**，会弹出一个系统级的独立置顶小窗（浏览器的「文档画中画」）：
- 它是真正的独立窗口，**天生置顶**，不需要安装任何软件；可自由拖动、缩放
- 里面同样能打勾，和网页、手机是同一份数据（勾完 1.5 秒自动上传）
- 再点一次 🪟 可以关掉；小窗自带关闭按钮，关闭不影响网页
- 要求：**电脑版 Chrome / Edge 116 以上**（现在主流版本都满足）。
  手机系统不允许网页浮在别的 App 上，所以手机端不显示这个按钮
  （手机上可以用「添加到主屏幕」+ 系统的小窗/分屏功能）。

### 每日韩语歌词
歌词放在 `lyrics.js` 里，每天自动显示一句（原文 + 翻译）：
- `startDate` 是第 1 句的日期（格式 `2026-10-16`）
- `lines` 里按顺序一句一个 `{}`，可到数组末尾后从头循环
- 每句可以带 `vocab`（词汇表），点「显示词汇」会列出并**在原文里把词汇标记出来**
- 卡片上的「上一句 / 下一句」只是本地翻看，不影响别人；点「回到今天」回到当天那句

改完 `lyrics.js` 后刷新页面即可生效（手机端刷新时用下拉刷新，别用缓存）。

## 本目录文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 样式（含手机端适配） |
| `app.js` | 界面逻辑 |
| `lyrics.js` | 每日韩语歌词内容（自己填） |
| `sync.js` | 数据层 + 云同步（GitHub Gist）+ 同步面板 |
| `sw.js` | Service Worker（离线可用、可安装） |
| `manifest.webmanifest` | PWA 清单（App 图标、名称等） |
| `icon.ico` | 桌面快捷方式图标 |

| `make-icons.js` | 重新生成图标的脚本（`node make-icons.js`） |
| `serve.js` / `本地预览.bat` | 仅用于本地预览，不必上传到 GitHub |
